# Telegram-бот «Адресная книга исполнителей» — MVP

## Возможности первой версии
- Поиск по ФИО, части телефона и специальности.
- Отдельный поиск по специальности.
- Вывод полного каталога постранично.
- Карточка исполнителя с готовностью работать, инструментом, автомобилем и комментарием.
- Оценка дисциплины с сохранением автора и даты последнего изменения.
- Доступ только для Telegram ID из allowlist.

## 1. Создайте бота
1. Откройте в Telegram `@BotFather`.
2. Выполните `/newbot`, задайте имя и username.
3. Скопируйте токен.

## 2. Подготовьте окружение
Python 3.11+ рекомендуется.

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Установите зависимости:
```bash
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_ALLOWED_USERS` — ваш числовой Telegram ID и ID коллег через запятую.

Не отправляйте токен в чат и не добавляйте `.env` в Git.

## 3. Загрузите контакты
Замените строки в `data/performers.csv` своими данными. Сохраните CSV в UTF-8.
Заголовки:
`full_name,phone,specialty,willing_to_work,has_tools,has_car,comment`

Для отметок используйте `1` или `0`. При первом запуске файл импортируется в SQLite.
Важно: текущая заготовка не импортирует повторно CSV автоматически после создания базы, чтобы не создавать дубликаты. Для последующих загрузок лучше добавить отдельную безопасную команду импорта.

## 4. Запуск
```bash
python bot.py
```

## Команды
- `/search Иванов`
- `/specialty Электрик`
- `/all`
- `/page 1`
- `/rate 1 1` — хорошая дисциплина у исполнителя с ID 1
- `/rate 1 0` — неудовлетворительная дисциплина

## Важные ограничения MVP
- Пока нет команд добавления/редактирования контактов.
- Оценка дисциплины хранит только последнюю оценку и её автора/дату, а не историю оценок.
- В этом шаблоне звёзды отображают четыре критерия, но дисциплина пока трактуется как бинарная отметка.
- Для нескольких специальностей у одного исполнителя позже лучше выделить отдельную таблицу.
- Перед реальным использованием проверьте корректность импорта, права доступа и резервное копирование базы.
